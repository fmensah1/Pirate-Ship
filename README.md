Project Description
This system allows pirate crew members to manage ship inventory with specialized storage compartments that have specific requirements:

Flammable Storage - For gunpowder, lantern oil, etc.

Liquid Storage - For rum, water, other liquids

Perishable Storage - For food with expiration dates

General Storage - For miscellaneous items
